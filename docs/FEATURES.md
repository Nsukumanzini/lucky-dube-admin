# Administration scope

Implemented: separate administrator sign-in, OG Vibes-inspired school overview with eight calculated metrics, attendance bars, review queue and agenda, grouped adaptive navigation, full-screen global search, paginated/sorted/filtered record directories, learner/staff registries, class capacities, subject grade configuration, teaching allocations, clash-aware timetable slots, academic terms, audited attendance correction, read-only mark review and release, resource review, targeted announcements, events/performing arts, support-case workflow, CSV reports, local activity history, school identity settings, bilingual UI and confirmed reset.

Not connected: no backend, no real account provisioning, invitations/password reset, live delivery, learner/teacher synchronisation, server-authoritative security, backup restore, government reporting submission, payment processing or production audit retention. No mass import or destructive bulk-delete feature is exposed. Existing archived records remain available for restoration.
